# Made Right Studio

🔗 **Live site:** [https://maderight.studio](https://maderight.studio)

A creative web design and development studio based in Columbia, South Carolina.

## Tech Stack

- **React** (Create React App)
- **GSAP** for scoped, performant animations
- **SplitText Plugin** for text-driven animations on headings and logos
- Scroll-triggered effects, hover interactions, and subtle continuous motion tuned to the brand's aesthetic

## Available Scripts

In the project directory, you can run:

### `npm start`
Runs the app in development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page reloads on changes.

### `npm test`
Launches the test runner in interactive watch mode.

### `npm run build`
Builds the app for production to the `build` folder, minified and optimized for best performance.
